# Guide diagrams

The `*.html` files in this folder are generated by archify from the
`*.workflow.json` source next to each of them:

| Diagram                                  | Source                         | Generated page        |
| ---------------------------------------- | ------------------------------ | --------------------- |
| Request routing by client key            | `key-routing.workflow.json`    | `key-routing.html`    |
| Credential selection inside the pool     | `pool-selection.workflow.json` | `pool-selection.html` |

Do not edit the HTML by hand. To change a diagram, edit its `*.workflow.json`, regenerate the
page with archify, and replace the HTML file here.

archify is a Claude Code skill (<https://github.com/tt-a1i/archify>), not a repository
dependency. The committed pages were generated with archify 2.16.0 (see the `generator` meta
tag). From the skill directory:

```sh
node bin/archify.mjs deliver workflow <path>/key-routing.workflow.json <path>/key-routing.html --quality showcase --json
```

Accept the result only when `deliver` exits with code 0 and reports all checks passed.

Tests depend on the generated pages:

- `GuidePage.test.tsx` looks for each diagram title (`meta.title` in the JSON source). If you
  rename a diagram, update those tests too.
- The same file checks the theme contract that `../DiagramFrame.tsx` relies on: the page reads
  `localStorage['archify-theme']`, styles both `data-theme` values, and exposes
  `Archify.theme.toggle`. If a newer archify version fails those checks, update
  `DiagramFrame.tsx` before replacing the HTML.

The pages contain archify's viewer code, MIT-licensed: Copyright (c) 2026 tt-a1i (Archify) and
Copyright (c) 2025 Cocoon AI (original "architecture-diagram-generator"). The notices are also
listed in the repository `LICENSE`.

The Guide page imports each HTML file as a string (`?raw`) and renders it in an
`<iframe srcDoc>` (see `../DiagramFrame.tsx`), so the pages are bundled into the single-file
panel build.

# 指南

指南页面说明 CPA 当前如何路由一个请求。在左侧导航最后一组、[系统信息](./system.md) 旁边打开。

## 图表

页面有两个标签页，每个标签页先给出简短说明，再展示一张可交互的图表：

- **按客户端密钥路由请求**：客户端密钥的路由配置、粘性会话绑定、首选账号、池内选择，以及在 429、5xx 或冷却后从 Claude 回退到 Codex。
- **池内凭据选择**：可用性过滤、首选账号、主槽位、决胜槽位、选择器，以及最终选中的凭据（没有剩余凭据时返回带 `Retry-After` 的冷却错误）。

点击某个阶段可以聚焦，可以缩放、平移画布，也可以用图表自带的控件导出图片。图表会跟随面板的浅色、深色或自动主题。

这些图表说明的是路由配置所控制的各个阶段，不会读取或修改你的配置。

## 图表如何生成

图表是用 archify 从 `apps/web/src/features/guide/diagrams/` 中的 `*.workflow.json` 源文件生成的独立页面，并被打包进单文件面板构建，因此 CPAMP 轻量面板和完整模式都无需额外文件即可使用指南。修改图表时，请编辑对应的 JSON 源文件，用 archify 重新生成 HTML 并替换 HTML 文件，不要手动编辑 HTML。

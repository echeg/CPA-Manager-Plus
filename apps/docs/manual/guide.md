# 指南

指南页面说明 CPA 当前如何路由一个请求。在左侧导航最后一组、[系统信息](./system.md) 旁边打开。

## 图表

页面有三个标签页，每个标签页先给出简短说明，再展示一张可交互的图表：

- **按客户端密钥路由请求**：客户端密钥的路由配置、粘性会话绑定、首选账号、池内选择，以及订阅这一轮失败后（例如 429、5xx 或冷却）该提供商的回退。Claude 可以回退到 Codex 订阅或配置中的 Claude API 密钥；Codex 只能回退到它自己的 API 密钥。API 密钥从不会被单独选中。
- **池内凭据选择**：可用性过滤、首选账号、主槽位、决胜槽位、选择器，以及最终选中的凭据。如果该提供商没有支持该模型的凭据，或者所有凭据都已关闭，请求会收到不带 `Retry-After` 的未找到错误。如果有凭据但都不可用：当所有凭据都处于冷却中或被硬预留占用时，返回带 `Retry-After` 的冷却错误；否则返回不可用错误（例如令牌已过期或被拒绝），只有在已知恢复时间时才带 `Retry-After`。在订阅模式下，池中只有 OAuth 凭据；API 密钥模式会跳过池，改用配置中唯一的 API 密钥。
- **通过 API 密钥路由**：请求何时会用到上游 API 密钥。路由配置为每个提供商设置模式：订阅（只用 OAuth 凭据）或 API 密钥（跳过订阅，所有请求都由配置中的密钥处理）。在订阅模式下，API 密钥回退只在订阅这一轮失败后才会尝试，并且这一段不会绑定会话，因此下一个请求仍会先尝试订阅。发往 API 密钥的请求计费到该密钥。

点击某个阶段可以聚焦，可以缩放、平移画布，也可以用图表自带的控件导出图片。图表会跟随面板的浅色、深色或自动主题。图表中的“复制链接”按钮在面板内无法生成可分享的链接。

这些图表描述的是本分支所用定制 CPA 后端（[echeg/CLIProxyAPI](https://github.com/echeg/CLIProxyAPI)）的路由：按密钥的路由配置、按提供商的订阅或 API 密钥模式、选择槽位，以及按提供商回退到 Codex 订阅或 API 密钥。原版 CPA 没有这些阶段。图表不会读取或修改你的配置。

## 图表如何生成

图表是用 archify 从 `apps/web/src/features/guide/diagrams/` 中的 `*.workflow.json` 源文件生成的独立页面，并被打包进单文件面板构建，因此 CPAMP 轻量面板和完整模式都无需额外文件即可使用指南。修改图表时，请编辑对应的 JSON 源文件，用 archify 重新生成 HTML 并替换 HTML 文件，不要手动编辑 HTML。

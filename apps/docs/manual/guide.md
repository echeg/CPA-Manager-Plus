# 指南

指南页面说明 CPA 当前如何路由一个请求。在左侧导航最后一组、[系统信息](./system.md) 旁边打开。

## 图表

页面有两个标签页，每个标签页先给出简短说明，再展示一张可交互的图表：

- **按客户端密钥路由请求**：客户端密钥的路由配置、粘性会话绑定、首选账号、池内选择，以及 Claude 这一轮失败后（例如 429、5xx 或冷却）从 Claude 回退到 Codex。
- **池内凭据选择**：可用性过滤、首选账号、主槽位、决胜槽位、选择器，以及最终选中的凭据。如果该提供商没有支持该模型的凭据，或者所有凭据都已关闭，请求会收到不带 `Retry-After` 的未找到错误。如果有凭据但都不可用：当所有凭据都处于冷却中或被硬预留占用时，返回带 `Retry-After` 的冷却错误；否则返回不可用错误（例如令牌已过期或被拒绝），只有在已知恢复时间时才带 `Retry-After`。

点击某个阶段可以聚焦，可以缩放、平移画布，也可以用图表自带的控件导出图片。图表会跟随面板的浅色、深色或自动主题。图表中的“复制链接”按钮在面板内无法生成可分享的链接。

这些图表描述的是本分支所用定制 CPA 后端（[echeg/CLIProxyAPI](https://github.com/echeg/CLIProxyAPI)）的路由：按密钥的路由配置、选择槽位以及 Claude → Codex 回退。原版 CPA 没有这些阶段。图表不会读取或修改你的配置。

## 图表如何生成

图表是用 archify 从 `apps/web/src/features/guide/diagrams/` 中的 `*.workflow.json` 源文件生成的独立页面，并被打包进单文件面板构建，因此 CPAMP 轻量面板和完整模式都无需额外文件即可使用指南。修改图表时，请编辑对应的 JSON 源文件，用 archify 重新生成 HTML 并替换 HTML 文件，不要手动编辑 HTML。
